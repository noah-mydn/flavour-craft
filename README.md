# FlavourCraft- An interactive AI-based personalized recipe recommendation system

## Overview

**FlavourCraft** is a full-stack web application built for personalized recipe generation and community sharing. It leverages AI models ( Cohere) to recommend recipes based on user preferences, dietary restrictions, and available ingredients. The platform features role-based access control, community interaction, and administrative management.

This project was developed as part of a final-year Bachelor's degree in Computer Science.

## Features

- 🔐 **Role-Based Access Control**: Admins and Customers with tiered permissions.
- 🧠 **AI-Powered Recipe Generation**: Integration with Cohere API to generate recipes.
- 📷 **Image Uploads**: Cloudinary for media handling.
- 👥 **Community Forum**: Users can post, comment, and engage.
- 📊 **Admin Dashboard**: Monitor statistics and manage campaigns.
- 🔒 **JWT Authentication + Google Login** for secure access.
